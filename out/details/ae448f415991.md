4. Standortfunktion „In meiner Nähe"
Die optionale Funktion „In meiner Nähe" ermittelt Veranstaltungen im Umkreis von 10 km um Ihren
Standort. Sie wird nur aktiv, wenn Sie sie ausdrücklich einschalten und die Standortfreigabe Ihres
Browsers erteilen. Einen Ort müssen Sie dafür nicht zuerst wählen.
Ihr Standort wird dabei ausschließlich über die Geolocation-Funktion Ihres Browsers
abgefragt. Die ermittelten Koordinaten werden ausschließlich lokal in Ihrem Browser
verarbeitet: Sie werden mit den in der Seite bereits enthaltenen Veranstaltungskoordinaten verglichen, um
die Entfernung zu berechnen und Veranstaltungen im gewählten Radius anzuzeigen. Die Koordinaten werden
weder an den Betreiber noch an einen externen Server oder Drittanbieter übertragen. Für die
Dauer der Sitzung werden sie lediglich im sessionStorage Ihres Browsers vorgehalten, damit die Auswahl beim
Zurückkehren erhalten bleibt; beim Schließen des Browsers werden sie gelöscht.
Unabhängig davon können Sie einen Heimatort speichern (siehe Abschnitt 3), damit die Startseite denselben
Ort merkt. Dieser Ort ersetzt nicht die Standortfreigabe für „In meiner Nähe".

Browser). Sie können die Einwilligung jederzeit widerrufen, indem Sie die Funktion deaktivieren oder die
